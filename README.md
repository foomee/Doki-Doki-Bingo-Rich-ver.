# ①課題名
ドキドキビンゴ

## ②課題内容（どんな作品か）
通常のビンゴにランダムイベントを追加したものです。  

## ③アプリのデプロイURL
https://foomee.github.io/Doki-Doki-Bingo-Rich-ver./

## ④アプリのログイン用IDまたはPassword（ある場合）
今回はありません。

## ⑤工夫した点・こだわった点
- 通常のビンゴにもう一つゲーム性を追加したかった。
- イベントの表示がいつ出現して、いつ消えるかなどは何度も確認した。
- ReactとNode.jsを使う予定があるのでjQueryを使わずに、素のJavaScriptで書くようにした。

## ⑥難しかった点・次回トライしたいこと（又は機能）
ビンゴの判定に二次元配列というのを採用していますが、もっと簡単な方法で実現することもできました。
しかし、勉強の為と拡張性を考えて、あえてこの難しい方法を選びました。
実はこれ以上に難しい所はたくさんあって、非同期処理のPromise と async / await らへんは理解するのに苦労しました。
まだ完全には理解しているとは思っておらず、モヤモヤがある感じです。

他には、処理の順番で上手くいかないことが多くて、コードを書く順番を変えたり、他の関数に移動したりみたいなことを試行錯誤しながらやりました。

今後、講義でFirebaseについて学ぶらしいので、その時にこのアプリのマルチプレイ版を作りたいです。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
今回のビンゴアプリは、JSの機能をたくさん使っていて、実はJSの勉強にとても良かったのではと思っています。
